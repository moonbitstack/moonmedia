Reel 02 · What it does

Read it, walk it, write it back

Each package does one job. A program that only needs playlists does not carry a container parser.

01

Byte for byte

A file is read into a tree of boxes and written back from it. A box this package has no name for keeps its payload and its header, so the bytes that come out are the bytes that went in.

02

Cuts on key frames

The packager splits a movie where a decoder can start: an initialisation section first, then one fragment per key frame, with the audio that belongs to it.

03

Every tag, either way

Master and media playlists, every tag of RFC 8216 and the low-latency additions. Attributes this release does not model are kept as they were written.

04

Tables that check themselves

PAT and PMT with their checksums, the programme clock, the continuity counter, and the elementary streams put back together with their timestamps.

05

Chunks assembled

Chunk streams with extended timestamps, AMF0 values, and the commands a publisher sends before its first frame, driven by a session you hand bytes to.

06

Manifests without a second library

DASH periods, adaptation sets, segment templates and timelines, read from XML and written back as XML.

Nothing here opens a socket or a file. Bytes in, bytes out; what to serve is the caller's business.
